BeanRegistrarDsl

open class BeanRegistrarDsl(init: BeanRegistrarDsl.() -> Unit) : BeanRegistrar

用于程序化注册 Bean 的契约。

通常通过在 `@Configuration` 类上添加一个 `@Import` 注解来导入。

@Configuration
@Import(MyBeanRegistrar::class)
class MyConfiguration {
}

在 Kotlin 中，通常使用 `BeanRegistrarDsl` 创建 bean 注册器，以便以简洁且灵活的方式程序化地注册 bean。

class MyBeanRegistrar : BeanRegistrarDsl({
	   registerBean<Foo>()
	   registerBean(
        name = "bar",
        prototype = true,
        lazyInit = true,
        description = "Custom description") {
            Bar(bean<Foo>())
    }
    profile("baz") {
        registerBean { Baz("Hello World!") }
    }
})
