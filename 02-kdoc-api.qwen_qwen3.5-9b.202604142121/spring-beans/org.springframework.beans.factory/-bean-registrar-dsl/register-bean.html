Parameters

T

bean 类型

name

bean 的名称

autowirable

设置此 Bean 是否为其他 Bean 自动注入的候选者。

backgroundInit

设置该 Bean 是否允许在后台线程中实例化。

description

该 Bean 的易读描述

fallback

设置该 Bean 是否为回退自动装配候选者。

infrastructure

设置该 Bean 是否具有基础设施角色，即与最终用户无关。

lazyInit

设置该 Bean 是否延迟初始化

order

该 Bean 的排序顺序

primary

设置该 Bean 是否为主要的自动装配候选者。

prototype

设置该 Bean 是否为原型作用域。
