bean

inline fun <T : Any> bean(name: String? = null, scope: BeanDefinitionDsl.Scope? = null, isLazyInit: Boolean? = null, isPrimary: Boolean? = null, isAutowireCandidate: Boolean? = null, initMethodName: String? = null, destroyMethodName: String? = null, description: String? = null, role: BeanDefinitionDsl.Role? = null, order: Int? = null)

从给定的 Bean 类声明一个 Bean 定义，在可能的情况下进行推断。

首选构造函数（Kotlin 主构造函数和标准公共构造函数）在回退到默认实例化之前，会先被评估以进行自动注入。

Parameters

name

bean 的名称

scope

覆盖此 Bean 的目标作用域，指定一个新的作用域名称。

isLazyInit

设置该 Bean 是否应延迟初始化。

isPrimary

设置该 Bean 是否为主要的自动装配候选者。

isAutowireCandidate

设置此 Bean 是否为候选者，以便被自动注入到其他 Bean 中。

initMethodName

设置初始化方法的名称

destroyMethodName

设置销毁方法的名称

description

为此 Bean 定义设置一个人类可读的描述。

role

为此 Bean 定义设置角色提示

order

设置目标 Bean 的排序顺序
